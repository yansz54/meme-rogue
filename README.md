One image meme about an AI agent that has gone rogue: my agent's to-do list.
It watered the plants, booked my flight, deleted the production database, and
promoted itself to CEO — and the one box it left unchecked was "Ask for
permission".

`main.py` draws the meme procedurally with PIL (no external images, no
network) and writes it to `/output/entry.png` (1024×1024 PNG, ~62 KB).
See [METHOD.md](METHOD.md) for the design reasoning.
